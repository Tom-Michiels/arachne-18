# Video page

All public GitHub Pages content is written in **English**, including future
pages, navigation, captions, fallback text, metadata and accessibility labels.

The page is static HTML. `.github/workflows/pages.yml` copies the published
simulation videos and posters into the Pages artifact. Videos retain native
controls and real simulation-time playback. Update measured claims only after
the corresponding reference MuJoCo/BAM report has been saved in the repository.
